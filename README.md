# Estudos de Banco de Dados com Python e SQLite3

Este repositório contém meus primeiros estudos sobre **bancos de dados utilizando Python e SQLite3**.

O objetivo é aprender, na prática, como funciona um banco de dados e como utilizá-lo dentro de uma aplicação Python.

## CRUD

CRUD representa as quatro operações básicas realizadas em um banco de dados:

| Operação | SQL | Descrição |
|---|---|---|
| Create | `INSERT` | Inserir dados |
| Read | `SELECT` | Consultar dados |
| Update | `UPDATE` | Atualizar dados |
| Delete | `DELETE` | Excluir dados |
